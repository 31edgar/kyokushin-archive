OUR PURPOSE

Searching Kyokushin content across the internet can be a bit difficult, and there are lots of videos that can only be watched after some time of research. Once I wondered about how useful it would be to have a website that gathered all the Kyokushin multimedia content we can find online. After that, I decided I was going to create this project from zero.

This project was born in order to accomplish the wish of having an online portal where everyone can enjoy and study this beautiful martial art. All content shown on this website is NOT in my possession. This is why everything is shown in embed or links, because my purpose is to reunite the content and it will never be to make profit from it.

I hope everyone can enjoy this platform and have a good experience while visiting here. I will try my best to find interesting content and adding new features to this site. Contact section is open to hear any request from every user, in order to improve kyokushin-archive.
